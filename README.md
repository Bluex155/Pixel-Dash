# Pixel-Dash
A game for ChromeOS and web


🎮 PIXEL DASH SUR CHROMEBOOK

🇫🇷 FR

Option 1 : Jouer tout de suite (sans installation)

Dézippe le dossier.
Ouvre Fichiers, fais un clic droit sur index.html, puis « Ouvrir avec Chrome ».

Le jeu fonctionne hors ligne. Le multijoueur marche sur le même Wi-Fi.

Option 2 : Installer comme une appli

Héberge gratuitement le dossier sur Netlify Drop ou GitHub Pages.
Ouvre le site avec Chrome (adresse HTTPS obligatoire).
Menu ⋮ > « Installer Pixel Dash ».

⚠️ Les fonctionnalités hors ligne nécessitent une installation via HTTPS. Elles ne fonctionnent pas en ouvrant directement le fichier.

🇬🇧 EN

Option 1: Play instantly (no installation)

Extract the ZIP folder.
Open Files, right-click index.html, then select "Open with Chrome".

The game works offline. Multiplayer works over the same Wi-Fi network.

Option 2: Install as an app

Upload the folder to free hosting such as Netlify Drop or GitHub Pages.
Open the website in Chrome (HTTPS required).
Menu ⋮ > "Install Pixel Dash".

⚠️ Offline features require installation through HTTPS. They won't work when opening the file directly.
